# Threadline

A clothing store website — static HTML/CSS/JS (no build step).

- `site/` – the storefront (home, shop with filters, product pages, wishlist, bag, checkout demo, about/FAQ/contact)
- `theme/` – an equivalent Shopify Online Store 2.0 theme (Liquid)

## Run locally

```bash
./dev.sh          # http://localhost:8080
```

Product photos are from [Unsplash](https://unsplash.com). Checkout is a demo; no payment is taken.
